# Pri Doce&ria — Bolos Artesanais

Site estático (um único `index.html`), pronto para o GitHub Pages.

## Como publicar

1. Crie um repositório no GitHub (ex.: `pridoceria`).
2. Envie **`index.html`**, **`.nojekyll`** e este **`README.md`** para a raiz do repositório (branch `main`).
3. No repositório: **Settings → Pages → Build and deployment**.
4. Em **Source**, escolha **Deploy from a branch**; em **Branch**, `main` e pasta `/ (root)`. Clique em **Save**.
5. Aguarde 1–2 minutos. O site ficará em `https://SEU-USUARIO.github.io/pridoceria/`.

> Dica: se o repositório se chamar `SEU-USUARIO.github.io`, o site abre direto em `https://SEU-USUARIO.github.io/`.
